# 从零部署运行指南（Windows / Linux 傻瓜版）

> 面向第一次运行本项目的同学：从"一台什么都没装的电脑"到"46 条用例全部跑通"，每一步照抄即可。
> 全程只需要 **Python + 一个浏览器**，不需要安装数据库、Node、Docker 等任何其他东西。

## 第 0 步：拿到项目代码（二选一）

**方式 A：装了 git**

```bash
git clone https://github.com/Wyy520-create/autotest.git
cd autotest
```

**方式 B：没装 git（最简单）**

打开 https://github.com/Wyy520-create/autotest → 绿色 `<> Code` 按钮 → `Download ZIP` → 解压 → 进入解压出来的 `autotest-main`（或 `autotest-主分支`）文件夹。

以下所有命令都在项目根目录（能看到 `requirements.txt` 的那个文件夹）执行。

## Windows 10 / 11

### 1. 安装 Python

1. 打开 https://www.python.org/downloads/ ，点黄色按钮下载 Python 3.11（或任意 3.8~3.12 版本）。
2. **运行安装程序的第一屏，务必勾选最下面的 `Add python.exe to PATH`**，然后点 `Install Now`。
   （不勾选的话后面所有 `python` 命令都会报"不是内部或外部命令"。）
3. 验证：按 `Win + R`，输入 `cmd` 回车，在黑窗口里执行：

```bat
python --version
```

看到 `Python 3.11.x` 即成功。如果提示找不到命令，重开一次 CMD 再试；还不行就是第 2 步没勾 PATH，重装一遍即可。

### 2. 安装浏览器（跑 UI 用例才需要）

装一个 **Chrome**：https://www.google.cn/chrome/ （或任意渠道下载安装）。
只跑 API / 数据库用例可以跳过这一步。

### 3. 创建虚拟环境并安装依赖（在项目根目录的 CMD 里执行）

```bat
python -m venv venv
venv\Scripts\activate
pip install -r requirements.txt
pip install -r sut\requirements.txt
```

执行成功后命令行最左边会出现 `(venv)` 字样。

### 4. 启动被测系统

```bat
python sut\app.py
```

看到 `mini-blog SUT 已启动: http://127.0.0.1:8520` 后，**这个窗口不要关**。

### 5. 运行测试

**再开一个 CMD 窗口**（同样 `cd` 到项目目录），执行：

```bat
venv\Scripts\activate
python run.py
```

期望看到 `46 passed` 字样，即全部通过。也可以只跑某一层：

```bat
python run.py api     :: 仅 API 用例
python run.py db      :: 仅数据库用例
python run.py ui      :: 仅 UI 用例（需要 Chrome）
```

## Linux（以 Ubuntu / Debian 为例，CentOS 命令附在最后）

### 1. 安装 Python 与 venv

```bash
sudo apt update
sudo apt install -y python3 python3-pip python3-venv
python3 --version    # 看到 Python 3.10+ 即可（Ubuntu 22.04 自带 3.10）
```

### 2. 安装浏览器（跑 UI 用例才需要）

二选一：

```bash
# 方式一：Chrome
wget https://dl.google.com/linux/direct/google-chrome-stable_current_amd64.deb
sudo apt install -y ./google-chrome-stable_current_amd64.deb

# 方式二：Firefox
sudo apt install -y firefox
```

> 注意：Ubuntu 的 Firefox 是 snap 版，在 Docker 容器 / 某些受限终端里可能起不来（snap 权限问题），此时请改用 Chrome。
> 纯服务器（无图形界面）跑 UI 用例：把 `config/config.yaml` 里 `browser.headless` 改成 `true` 即可无头运行。

### 3. 创建虚拟环境并安装依赖（在项目根目录执行）

```bash
python3 -m venv venv
source venv/bin/activate
pip install -r requirements.txt
pip install -r sut/requirements.txt
```

### 4. 启动被测系统

```bash
python3 sut/app.py
```

看到 `mini-blog SUT 已启动: http://127.0.0.1:8520` 后不要关闭这个终端。

### 5. 运行测试

新开一个终端（同样 `cd` 到项目目录）：

```bash
source venv/bin/activate
python3 run.py        # 全部用例
```

### CentOS / Fedora / RHEL 命令对照

| Ubuntu | CentOS/Fedora |
| --- | --- |
| `sudo apt install -y python3 python3-pip python3-venv` | `sudo dnf install -y python3 python3-pip` |
| `sudo apt install -y ./google-chrome-*.deb` | 去 https://www.google.com/chrome/ 下载 `.rpm` 后 `sudo dnf install -y google-chrome-*.rpm` |
| `sudo apt install -y firefox` | `sudo dnf install -y firefox` |

其余步骤完全相同。

## 常见问题（FAQ）

### Q1：`python` 命令不存在 / `'python' 不是内部或外部命令`

- Windows：Python 安装时没勾 PATH。重装 Python 并勾选 `Add python.exe to PATH`；或临时用 `py` 代替 `python`（Windows 的 Python 启动器）。
- Linux：用 `python3` 代替 `python`（本文 Linux 部分已全部使用 `python3`）。

### Q2：跑 UI 用例时 Chrome 驱动下载很慢或失败

框架用 webdriver-manager 自动下载匹配版本的 chromedriver，国内网络可能较慢。两种解法：

1. 重试几次，或挂代理；
2. 手动下载 Chrome for Testing 解压后指定路径：

```bash
# Linux 示例
wget https://storage.googleapis.com/chrome-for-testing-public/154.0.8037.57/linux64/chrome-linux64.zip
unzip chrome-linux64.zip -d ~/cft
export AUTOTEST_CHROME_BINARY=~/cft/chrome-linux64/chrome
python run.py ui
```

### Q3：8520 端口被占用

换个端口启动被测系统，并让框架知道：

```bash
python sut/app.py --port 9000
export AUTOTEST_BASE_URL=http://127.0.0.1:9000     # Windows 用 set AUTOTEST_BASE_URL=http://127.0.0.1:9000
python run.py
```

### Q4：UI 用例报浏览器相关错误，但我只想看接口/数据库测试

```bash
python run.py api && python run.py db    # 完全不需要浏览器
```

### Q5：想重置被测数据

删掉 SQLite 文件再重启被测系统即可：

```bash
rm sut/blog.db           # Windows: del sut\blog.db
python sut/app.py
```

### Q6：Allure 报告想看漂亮结果页

```bash
pip install allure-pytest   # 已在 requirements.txt 中
# 安装 allure 命令行（二选一）：
#   Windows: scoop install allure  或下载 zip 解压加 PATH
#   Linux:   sudo apt install -y allure  不可用则用: sudo snap install allure
pytest --alluredir=reports/allure-results
allure serve reports/allure-results
```

不想装 allure 命令行也能看 HTML 报告：

```bash
pytest --html=reports/report.html --self-contained-html
# 然后用浏览器打开 reports/report.html
```
